# Research attribution

The commerce experiment builds on published models, data, and code. Source revisions and checksums are recorded in the [experiment report](/research/commerce).

| Source | Use | License text |
| --- | --- | --- |
| Amazon ESCI | Product-query examples and labels | [Apache 2.0](/downloads/experiments/commerce-001/licenses/ESCI-Apache-2.0.txt) |
| JevK5 | Model recipe and checkpoint | [Apache 2.0](/downloads/experiments/commerce-001/licenses/JevK5-Apache-2.0.txt) |
| SemIf-OpenJev | Option-logit and prompt pattern | [MIT](/downloads/experiments/commerce-001/licenses/SemIf-MIT.txt) |

The recorded commerce demo uses a modified subset of the source product metadata. HTML is removed, text is bounded, and model predictions are added. The underlying Qwen3.5-4B model provenance is described in the JevK5 model card linked from the report.
