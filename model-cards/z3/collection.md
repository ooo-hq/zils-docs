# z3 — Zils decision models

The Zils decision-model line: founding baselines and approved miner-trained
releases. Each model size has its own lineage and qualification.

Initial entry: z3-mini v1, the founding baseline using unchanged upstream d3-mini
weights. This baseline is not an election winner. Elected successors receive
separate versions and published evidence.

Only approved releases belong in this collection. Candidate submissions and
unreleased sizes are excluded.
